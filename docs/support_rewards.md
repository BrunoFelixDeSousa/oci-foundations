# Oracle Support Rewards

**Oracle Support Rewards** é um programa que oferece valor adicional aos clientes que utilizam serviços de OCI e, ao mesmo tempo, têm licenças de software Oracle em seus ambientes on-premises. 

Com base no consumo de serviços OCI, os clientes podem acumular **Support Rewards**, que podem ser aplicados como uma forma de pagamento para **atualizações de licenças de software** e **suporte de programas tecnológicos da Oracle**.

Quanto mais serviços OCI um cliente consumir, maior será o desconto no custo de suporte de suas soluções on-premises.
