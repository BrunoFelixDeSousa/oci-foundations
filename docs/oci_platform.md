# Plataforma Oracle Cloud Infrastructure (OCI)

**Blocos de construção da Oracle Cloud Infrastructure**:

## Infraestrutura Principal
- **Computação**
  - Bare Metal, Máquinas Virtuais (VM), CPUs, GPUs, HPC
- **Contêineres**
  - Containers
- **Sistemas Operacionais**
  - VMware
- **Armazenamento**
  - Block, Object, Archive, entre outros
- **Redes**
  - VCN, VPN, etc.

## Banco de Dados
- **Bancos de Dados Oracle**
  - OLTP, OLAP, JSON, etc.
- **Bancos de Dados Distribuídos e Open Source**
  - NoSQL, MySQL

## Dados e IA
- **Big Data**
  - Data Flow, Data Integration, entre outros
- **Serviços de IA**
  - Data Science
- **Mensageria**
  - Streaming, Queueing

## Análise
- **Análises Empresariais**
  - Business Analytics

## Aplicações
- **Serverless**
  - Eventos, Funções, API Gateway
- **Integração de Aplicativos**
  - Integration Cloud, entre outros
- **SaaS para Negócios e Indústrias**
  - ERP, HCM, SCM, Vendas, etc.

## Governança e Administração
- **Operações na Nuvem**
  - IAM, Compartimentos, Etiquetagem, Consultor de Custos
- **Segurança**
  - Cloud Guard, Segurança, etc.
- **Observabilidade**
  - Monitoramento, Logging, entre outros

## Serviços para Desenvolvedores
- **Low Code**
  - APEX
- **Desenvolvimento de Aplicativos**
  - Visual Builder Studio, GraalVM, etc.
- **Infraestrutura como Código**
  - Terraform, Ansible, entre outros
